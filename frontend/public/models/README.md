# 3D model files for /lab/models

Real 3D models (`.glb`, compressed with meshopt) loaded by `src/lab/models/gltfModel.js`.
Every file here must have a licence that allows use on the school platform, and an entry
in `src/lab/models/catalogue.js` with its `credit` (title, author, source, url, licence).
Keep each file small (aim for 1–5 MB) so it loads on phones.
